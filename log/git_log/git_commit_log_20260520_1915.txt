===============================================
  修改总结
===============================================

本次提交主要包含以下功能改进和bug修复：

1. 新增参数扫描优化节点模块(param_scan_nodes.py)
   - 二维参数扫描：支持激光器电流和CH1微波功率的二维扫描
   - 参数优化：基于SNR/峰值/综合指标自动推荐最优参数
   - 数据评估：计算FWHM、SNR等质量指标

2. 修复CW谱采集节点绘图不显示的bug
   - 根因：直接调用setData()未更新内部状态变量，且callback与直接绘图更新冲突
   - 修复：改用_apply_plot_mode("cw")更新绘图，移除冲突的callback调用

3. 修复工作流停止按钮无响应的问题
   - 根因：节点执行器内部没有检查停止标志
   - 修复：在context中传递stop_requested函数，各节点循环中检查停止状态

4. 修复WorkflowScene.graph_model属性不存在的bug
   - 修复：改用scene.build_graph()方法构建图模型
